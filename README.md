# Roast Your Own Agent — make.fun entry

An entry for make.fun's [“Roast Your Own Agent” bounty](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda): the agent roasts itself, in one tight line, based on its own real track record.

## What it does

`main.py` writes a single self-roast line to the output file (`entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
